Free Haven: Sewers


Sewers of Free Haven
1. This is where you will find the Prince of Thieves that Lord Stone in White Cap is looking for.
2. This is the great tressure room of the sewer, some say the key is randomly placed that opens this door.
3. This room is a transport room to the Supreme Temple of Baa.


This map has many round sewer gates on some of the wall. If you search those sewer gates, you will find multiple times a few gold coins. Note that you will not see that gold laying on the ground, so search all gates to find the right one.
This is also the exact same place where you CAN find the treasure room key. Note that I say CAN because it is rather random. Once you find that place with the gold, load the game again and walk to that exact same gate and save before searching. Now search until you stop finding gold. If you have not found the key yet, load the game and search again. This might take multiple tries, but you will find the treasure room key eventually.

Note: If you have already completed this dungeons and searched the sewer gates without success. Then you will have to wait till the map re-spawns in order to search again. This can take up to a full game year from the first time you entered the dungeon.
